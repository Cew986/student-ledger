# 生活费记账（Pocket Ledger）

单文件 PWA 记账应用，专为学生月度生活费管理设计。**零框架、零构建、零 CDN 依赖**——一个 `index.html` 走天下，数据全部存在你自己手机里。

## 功能一览

- **每月总预算**：月初按你设定的生活费自动生成（默认 ¥2400，含 8 个分类模板）
- **分类预算 = 关键字 + 金额**：自己定义「餐饮 1100」「话费 120」等预算项，每个预算项挂一组关键字（如「食堂、美团、外卖」），账单按关键字自动归类，未命中归入「其他」
- **预算对比**：每个分类显示 已用 / 预算 / 百分比 / 剩余，≥80% 变橙、超支变红；顶部有总预算 vs 总支出汇总
- **追加预算**：爸妈多给的报销随时加上，只进预算池，不会混进收入流水
- **记一笔**：2 秒手动记账，支持「不占预算」标记（买电脑、买衣服这类大额不污染月度预算）
- **微信 / 支付宝账单导入**：手动上传 CSV，自动识别来源、自动去重、自动跳过退款与不计收支行，支持一键撤销整批导入
- **统计**：分类占比、近 6 个月趋势、对比上月
- **备份**：一键导出 JSON（含全部数据），换机/重装可恢复
- **PWA**：添加到桌面后全屏运行、离线可用、支持系统「分享」直达导入

## 安装到手机（Android）

1. 用 Chrome 打开部署好的地址（见下方「部署」）
2. 菜单 → **添加到主屏幕 / 安装应用**
3. 桌面出现独立图标，点开即全屏运行，离线也能用

## 部署到 GitHub Pages（3 分钟）

1. 新建仓库，例如 `student-ledger`（公开）
2. 把本目录所有文件传上去（`index.html`、`sw.js`、`manifest.webmanifest`、`icons/` 必须在仓库根目录）：

   ```bash
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/student-ledger.git
   git push -u origin main
   ```

3. 仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)` → Save
4. 一分钟后访问 `https://<你的用户名>.github.io/student-ledger/`，手机 Chrome 打开并安装

> 仓库里已包含 `.nojekyll`，GitHub Pages 不会忽略下划线开头文件。

## 导入微信账单（手动导出 CSV）

手机操作路径（微信 8.x）：

1. **我 → 服务 → 钱包 → 账单**（或「支付 → 钱包 → 账单」）
2. 右上角 **常见问题 → 下载账单 → 用于个人对账**
3. 选时间范围（建议按月）→ 填邮箱 → 几分钟后收到带下载链接的邮件
4. 电脑或手机浏览器打开链接下载 CSV（**zip 里是 csv，注意解压**）
5. 回到本应用：设置 → 导入账单 → 选中该 CSV → 确认导入

## 导入支付宝账单（手动导出 CSV）

1. 支付宝 App：**我的 → 账单 → 右上角 ... → 开具交易流水证明 → 用于个人对账**
2. 选时间范围 → 填邮箱 → 收到带 **解压密码** 的邮件（密码在另一封服务通知里）
3. 下载 zip，解压得到 csv（电脑解压最方便；手机可用文件管理器解压）
4. 本应用 → 设置 → 导入账单 → 选中该 CSV → 确认导入

> 支付宝导出的也可能是 **xls/xlsx**（App 版本不同入口不同）。若是表格文件，请在电脑上用 WPS/Excel 另存为 **CSV UTF-8** 再导入。本应用解析纯 CSV 文本。

### 导入时自动处理的东西

| 情况 | 处理方式 |
|---|---|
| 重复账单（同一订单号） | 硬重复，自动跳过，不可勾选 |
| 疑似重复（无订单号但时间/金额/对方相同） | 默认跳过，可手动勾选保留 |
| 退款 / 已关闭 / 提现 / 充值 / 不计收支 | 自动过滤，不进预算 |
| 商品名含逗号、GBK/UTF-8/UTF-16 编码 | 自动处理 |
| 归类 | 按预算项关键字匹配，未命中归「其他」 |

## 想要「自动/实时」记账怎么办？（重要说明）

**网页/PWA 拿不到微信和支付宝的实时数据**——个人账号没有账单读取接口，网页也读不到系统通知，这是平台限制，任何网页应用都一样。账单导入永远是「你先导出、再上传」的手动流程（建议**每月月初导一次上个月的**，一分钟搞定）。

想要「实时记账」的体验，可用配套原生 App 做**日常流水**，本应用做**月度预算精算**：

- 推荐 **AutoBookkeeper**（MIT 开源，100% 本地，不上传数据）：
  `https://github.com/sadrass05/autokeeper`
- 原理：Android 的通知读取权限（NotificationListenerService），微信/支付宝支付成功弹出通知时自动记一笔
- 配置要点：
  1. 安装后授予 **通知使用权**（设置 → 通知读取）
  2. 在系统设置里给它 **关闭电池优化** + 加入自启动/后台白名单（否则杀后台就抓不到）
  3. 它导出的 CSV 同样可以导入本应用做月度汇总
- 风险提示：通知抓取会把 **红包、转账、退款** 也记成支出，会有误差——**预算执行情况以本应用导入官方账单为准**，实时数据仅作参考

## 备份提醒

数据存在浏览器 IndexedDB 里，**清除浏览器数据 = 数据全没**。建议：

- 每月月初导出一次备份（设置 → 导出备份），存到网盘
- 换手机/重装系统后用「导入备份」恢复

## 目录结构

```
├── index.html              # 全部 UI + 逻辑（单文件应用）
├── sw.js                   # Service Worker：离线缓存 + 分享直达
├── manifest.webmanifest    # PWA 清单（图标/安装/分享目标）
├── icons/                  # 应用图标（tools/make-icons.py 生成）
├── samples/                # 脱敏样例账单，可直接导入测试
│   ├── wechat-sample.csv
│   └── alipay-sample.csv
├── tools/
│   ├── make-icons.py       # 零依赖图标生成器（python tools/make-icons.py）
│   └── test-parser.mjs     # CSV 解析器自测（node tools/test-parser.mjs）
└── .nojekyll
```

## 本地开发 / 自测

```bash
python -m http.server 8765        # 起本地服务（IndexedDB/SW 需要 http:// 来源）
# 浏览器打开 http://127.0.0.1:8765/index.html

node tools/test-parser.mjs        # 解析器单元自测（用 samples/ 真实格式样例）
python tools/make-icons.py        # 重新生成图标（改配色后）
```

## 隐私

- 不收集任何数据，无统计 SDK，无 CDN 请求，完全离线可用
- 账单文件只在导入瞬间被浏览器读取解析，**不会上传到任何服务器**
- 代码全部可审计：一个 HTML、一个 JS、一个 manifest
